HomepageHi, I’m Tamara, and this is ClosetAI: an AI stylist that helps women in Mexico decide what to wear from the clothes they already own.
/demo, topFor six weeks I built it one module at a time. This last week I joined them into one venture, and I had to prove three things: that it works, that it creates value, and that it avoids obvious harm. Everything starts here, at closetai.lat/demo.
Menu on every pageBefore, each page only linked back home. Now one navigation reaches every module, on a computer and on a phone.
/demo, the stepsThe demo page is a guided tour: nine steps, each one opens a live page and says what to notice.
/chat, the questionsStep one: anyone can ask the stylist without an account. It asks four short questions: the section you shop in, the occasion, the weather and your style.
/chat, the outfitThen the AI builds an outfit, explains why it works and gives one tip. Each garment has an inspiration photo, credited to its photographer, and links to find something similar in real stores.
/chat, the guardrailAnd this is what it won’t do. A question about losing weight never reaches the AI. It gets a kind, fixed answer, and a person reviews the conversation.
The app (Week 0 video)With an account, ClosetAI catalogs each garment from one photo, suggests outfits from your own closet with the real weather, and shows clothes on you with a virtual try-on.
/dashboardThis is the new dashboard. Every number is read from the database when you open it. The numbers are small, and they are all true: nothing is estimated, and test traffic is left out. It also shows what the AI has cost: less than one dollar since August.
/docsThe docs page shows how it was built: every prompt my AI agents use, exactly as production sends them, and the plan for each week, always written before the code.
/demo, agent mapThis is the agent map. ClosetAI runs ten AI agents. For each one you can see what goes in, what comes out, what stops it from making things up, and where a person decides instead of the AI.
/demo, testingFive people outside the project tested it on their own phones. Their words appear here exactly as they wrote them. One of them said the only confusing thing was that it’s in English, so a Spanish version is now on the roadmap.
/demo, regressionI also ran an automated test of the whole site against the real page. Its first run failed: three pages never finished loading. I fixed it, and the second run passed.
/demo, impact checkThe impact check pairs each risk with what stops it, and with the test that proves it. Building the dashboard, I found old visitor IP addresses saved in the database, so I deleted them.
/demo, Version 2And this is version two. Every idea comes from evidence, like my weakest number: most outfits in the app were rejected, so the stylist has to learn from those reasons first.
